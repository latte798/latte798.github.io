Q.

  • Spring Framework가 탄생하게 된 배경과 이를 통해 해결하고자 했던 문제점에 대해 설명하세요.
  • 프레임워크와 라이브러리의 차이점을 제어 흐름의 주체와 사용 방식을 중심으로 설명하고, Spring Framework와 일반 Java 라이브러리를 예시로 들어 설명하세요.

A.

1. spring 탄생배경와 해결하고자 한 문제

EJB 라고 하는 과거 프레임 워크의 설정과, 사용의 복잡성을 극복하기 위한 새로운 객체지향적인 프레임워크의 필요성이 대두되었다.

다음과 같은 목적을 위해 제작되었다.

  1. 순수한 자바 객체를 이용 - POJO
  2. 객체 지향적 구조를 설계
  3. 유지 보수 및 테스트가 쉬운 코드 - TDD

2. 프레임워크, 라이브러리

둘의 가장 큰 차이는 제어의 주체이다. 프레임워크는 전체적인 뼈대와 흐름을 스스로 제어하며 재발자의 코드를 호출. 라이브러리는 개발자가 흐름을 주도하며, 필요시마다 도구처럼 호출하여 사용.

프레임워크의 예로, spring boot 는 bean 으로 객체를 등록, 객체의호출과 사용을 spring 이 담당한다.

반면 라이브러리는 jackson 이나 기본 자바 라이브러리와 같이, 개발자가 명시적으로 import 한 후, 코드를 작성해서 사용한다.

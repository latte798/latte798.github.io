Q.

  • 웹 서버(Web Server)와 WAS(Web Application Server)의 차이를 설명하고, Spring Boot의 내장 톰캣이 이 둘 중 어디에 해당하는지 설명해주세요.
  • Spring Boot에서 사용되는 다양한 Bean 등록 방법들에 대해 설명하고, 각각의 장단점을 비교하세요.

A.

1. 웹서버 와 WAS 의 차이, SPRINGBOOT 의 내장 톰캣은 어디에 소속되는가?

웹 서버와 WAS 의 차이는 동적인 애플리케이션 로직을 실행할 수 있는가 이다.

웹서버는 요청에 대한 정적 리소스의 제공이 주 역할이다. nginx, apache 와 같은 서버가 해당 역할을 한다.

WAS 는 요청에 대해 프로그램 코드를 실행 할 수 있는 서버이다.

Spring boot 톰캣 의 경우,

2000년대부터 2013년대에 별도로 설치하는 서버였다.

2014년 부터 라이브러리로 감싸 스프링 자체에 내장된 WAS 로서 사용되기 시작했다.

2. SpringBoot 에서 사용되는 다양한 Bean 와 각각의 장단점.

SpringBoot 의 스테레오타입 어노테이션은 다음과 같다.

  • @Compnent 기본이 되는 어노테이션. @Bean으로 발행하는 과정을 자동화 한 어노테이션.

  • @Service 서비스 계층을 나타내는 어노테이션. @Component와 차이는 없다. 가독성을 위해 구분해서 사용하는 어노테이션.

  • @Repository 레파지토리 계층을 나타내는 어노테이션. 형태는 거의 같으나, 데이터 소스에서 나온 예외들을 DataAccessException 으로 모아서 반환한다.

  • @Controller / @RestController 웹 요청을 처리하는 컨트롤러를 나타내는 어노테이션. 스프링 웹 요청 핸들러에 등록되어, 요청에 따라 작성된 매서드를 실행한다.
